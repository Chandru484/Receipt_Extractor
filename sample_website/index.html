💻 How this Website Embeds the Chatbot Widget

To add the Universal AI Chatbot to any external website or portal, your developers simply drop this script tag into the page HTML. It automatically inherits the logged-in user's credentials and package: 

<!-- Universal AI Chatbot Embed Snippet -->
<script
  src="http://localhost:8080/widget.js"
  data-project-id="apex_portal"
  data-user-id="usr_priya_101"
  data-role="user"
  data-package-id="pkg_retail_01"
  data-voice="muted"
  async>
</script>
